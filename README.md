НАША БИБЛИОТЕКА РОБОТЕХНИКИ (Заголовок)
Практическая работа? (Краткое описание)

Задание: Репозиторий «Наш Робо-Стек»

Представьте, что вы создаете общую базу знаний для ваших будущих проектов.

Этап 1: Настройка (Делает Участник А)
    Создает публичный репозиторий на GitHub (например, our-robotics-library).
    Добавляет файл README.md с заголовком и кратким описанием.
    В настройках репозитория (Settings -> Collaborators) добавляет Участника Б по никнейму.

Этап 2: Параллельная работа
    Теперь оба участника клонируют репозиторий себе на компьютеры и делают следующее:

    Участник А:
        Создает ветку feature-electronics.
        Создает папку docs/ и в ней файл hardware.md.
        Пишет туда список любимых компонентов (например: ESP32, драйвер моторов L298N, датчик VL53L0X).
        Делает commit и push ветки в GitHub.

    Участник Б:
        Создает ветку feature-software.
        В той же папке docs/ создает файл libraries.md.
        Пишет список библиотек (например: WiFi.h, FastLED, MadgwickAHRS).
        Делает commit и push ветки в GitHub.

Этап 3: Слияние (Pull Requests)
    Каждый заходит на страницу репозитория и нажимает "Compare & pull request".
    Участник А проверяет и одобряет PR Участника Б.
    Участник Б проверяет и одобряет PR Участника А.
